# Safarah-App-


**About**

Safarah is a Quran Revision focused app which allows users who have memorized all or parts of the quran to test their memoirzaton both at the moment and over time using useful features which i will explain more below:

**Ver 1.0.0**  
This version is simply for individuals who would like to download and test the app while also utilizing the useful features it provides, this is not yet the final verison of the application.

**Quran Revision**

Safarah allows users to completely turn quran pages blank, allowing users to reveal the page ayah by ayah as they go through the page using multiple tools including:

-tap to reveal

-volume buttons 

-recitation
